# 上漲谷中控（szg-hub）

給同時玩很多個帳號的人用的「中控面板」：把每個 Chrome 設定檔裡的 [上漲谷](https://play.szg08.com/game/) 角色資料集中到一個網頁，
並且可以從面板批次交易、整理背包、控制掛機、自動回答知識王。

- 全部在你自己的電腦上執行：一個本機小伺服器（Node.js）＋每個 Chrome 設定檔裡的 Tampermonkey 腳本。
- 不需要、也不會碰任何帳號密碼；資料只存在你電腦的 `data/` 資料夾，不會上傳到任何地方。
- 會動到遊戲資料的操作（交易、賣出、鎖定）都要先在面板上「確認執行」才會開始。

> 使用前請自行確認遊戲的使用規範。本專案與遊戲官方無關，使用造成的任何損失請自行負責。

## 功能一覽

| 分頁 | 可以做什麼 |
|---|---|
| 總覽 | 所有角色的等級、經驗、每小時經驗、地圖、掛機狀態、楓幣、藥水存量；一鍵開始／暫停掛機、自動續掛；從面板切換各帳號的目前角色 |
| 裝備 | 穿戴對照表；所有裝備（穿戴＋背包＋倉庫）的清單，可用素質條件（> < = ≠，且／或）篩選；批次鎖定／賣出；撿到不合條件的裝備自動賣掉 |
| 資源 | 楓幣總和、每種道具分布在哪些角色身上、各分身可收集的東西 |
| 交易 | 分身 → 本尊「收集」、本尊 → 指定角色「分發」，自動拆批（每次 20 格、每格最多 9999、5% 手續費） |
| 背包 | 依篩選條件勾選，批次賣出／鎖定／解鎖、一鍵全賣 |
| 市場 | 行情查價（定時掃描、市場最低價／中位數、7 日最低／平均／漲跌、持有估值）、各帳號攤位與成交紀錄、自動領收益、依規則自動定價上架 |
| 知識王 | 內建題庫，自動作答；題庫沒有的題目停下來讓你在面板上選，答過的會自動收進題庫 |

## 一、安裝（只要做一次）

### 1. 安裝 Node.js
到 https://nodejs.org 下載 **LTS** 版，一路「下一步」安裝完成。裝完建議重新開機一次。

### 2. 下載中控並啟動
1. 本頁上方按 **Code → Download ZIP**，解壓縮到固定位置，例如 `D:\szg-hub`。
2. 雙擊 `start.bat`。
3. 出現黑色視窗、顯示「上漲谷中控已啟動」，瀏覽器會自動打開面板 `http://127.0.0.1:8787`。

**玩的時候讓黑色視窗開著**，關掉就停止。

### 3. 每個 Chrome 設定檔都做一次
1. 安裝 [Tampermonkey](https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo)（竄改猴）。
2. 打開 `chrome://extensions` → Tampermonkey →「詳細資料」→ 開啟 **「允許使用者指令碼」**（新版 Chrome 沒開的話腳本不會執行）。
3. 中控開著的狀態下，網址列打開 `http://127.0.0.1:8787/szg-hub.user.js` → Tampermonkey 跳出安裝畫面 → 按「安裝」。
4. Tampermonkey 圖示 →「控制台」→「設定」：
   - 「設定模式」改成 **進階**
   - 找到 **外部（Externals）→ 更新間隔（Update Interval）**，改成 **總是（Always）**

   這一步讓腳本每次載入都拿到中控上最新的功能，之後更新就不用再動 Tampermonkey。

### 4. 打開遊戲
遊戲頁面右下角出現綠色的 **「中控：已連線」** 就完成了，回到面板就會看到這個角色。

## 二、日常使用

### 基本觀念
- **一個帳號的第二隻角色**：遊戲只給目前角色的完整資料，所以要切換到那隻角色一次，它才會完整出現在面板上。可以直接在總覽表角色名稱旁按「⇄ 切換」。
- **灰色列**：超過 5 分鐘沒更新，通常是那個設定檔的遊戲分頁沒開。
- **本尊**：在總覽表點 ★ 指定哪隻是本尊，交易的「收集」會把東西集中到本尊。
- **工作佇列**：交易、賣出、鎖定都會先建立成「待確認」工作，核對內容後按「確認執行」才會開始。執行時相關角色的遊戲分頁要開著，並切到那隻角色。

### 總覽：掛機控制
- 勾選角色 → **▶ 開始掛機／Ⅱ 暫停掛機／↻ 重新開始**（重新開始＝重新計算 24 小時）。同帳號的第二隻角色也可以直接勾。
- **自動續掛**：到期前 N 分鐘自動重新開始；從面板手動暫停的不會被重新開始。
- **掛滿 N 小時自動暫停**。
- 每列的「自動」取消勾選就不套用自動規則。
- **切換角色**：角色名稱旁標「目前」的是那個帳號正在操作的角色；按另一隻旁邊的「⇄ 切換」，或勾選多隻後按「⇄ 切換為目前角色」，該帳號的遊戲分頁會切換並自動重新整理（約 10 秒）。帳號有交易／背包工作在執行時不能切換。背包操作、交易都要在指定角色是「目前」時才會執行。

### 裝備
- **穿戴對照**：每隻角色一列、每個部位一欄；「各部位要顯示哪些素質」可以每個部位分開設定。
- **裝備清單**：可依部位、位置、職業、角色、名稱、需求等級、強化次數、剩餘可衝次數、素質條件篩選，點表頭排序，表頭會固定在畫面上方。
  - 素質條件可用 `>` `>=` `<` `<=` `=` `≠`，條件之間選「且」或「或」。**「且」優先**：`A 且 B 或 C` ＝ `(A 且 B) 或 C`。
  - 除了各項素質，也能用「四屬總和、強化次數、剩餘可衝、總可衝次數、需求等級」當條件。
  - 常用的篩選按「存成組合」，交易和背包的篩選器也能直接套用。
  - 勾選背包裡的裝備 → **鎖定／解鎖／賣出**，會依角色建立工作。
- **撿到裝備自動處理**：
  - 每條規則設定「對象」（部位、名稱、職業）和「保留條件」。新出現在背包、符合對象但不符合保留條件的裝備會被處理；多條規則都套到同一件時，符合任一條的保留條件就保留。
  - 模式：**關閉／試跑（只記錄會賣哪些）／自動賣出**，並勾選要套用的角色。
  - 一律不動：已鎖定、強化過、衝過卷的裝備；剛透過中控交易進來的裝備；開啟前就在背包裡的裝備。
  - ⚠ 腳本只看得到「背包多了哪一件」，分不出是撿到的還是你自己從倉庫拿出來、手動交易收到的。重要裝備請先鎖定，並建議先用「試跑」確認規則正確再開自動賣出。

### 交易
- **收集**：勾選分身，把背包裡可交易的道具、裝備、楓幣送到本尊。可以設定每個分身保留多少 % 楓幣（買藥用）。固定排除：穿在身上的裝備、補給使用中的藥水、已鎖定的物品、倉庫內的東西。
- **分發**：選「從誰」「給誰」，從下拉選單挑實際擁有的道具、勾裝備、填楓幣。
- 自動拆成每次最多 20 格；同種道具超過 9999 個會拆到不同批次。
- 安全機制：收貨方只接受清單上指定帳號的邀請，並逐項核對對方放的東西，不符就取消；放東西前會再檢查一次鎖定狀態；任何一步卡超過 3 分鐘自動取消，可按「重試」從失敗的批次繼續。
- 同帳號的兩隻角色不能互相交易，請用倉庫。
- **第一次用建議先小量測試**，例如分發一個道具 ×1。

### 背包
選角色 → 篩選 → 勾選 → **賣出／鎖定／解鎖**；「全選可賣的」等於一鍵全賣。賣出時會再跳過鎖定的物品與補給中的藥水，報價項目比選擇的多時自動停止。

### 市場（自由市場）
- **行情**：中控會定時（預設每 3 小時，可改）用遊戲的市場搜尋查詢「所有帳號背包裡有的道具」，記錄：
  - 市場最低價、前 50 件的中位數、掛單筆數／總數量（都是**單件價**，並**排除自己帳號的掛單**）
  - 7 日最低／平均／最高、漲跌（和約一天以上前比）、每日走勢
  - 你所有帳號持有的數量與估值（持有 × 市場最低價）
  - 點一列可以展開目前最便宜的幾筆掛單。
  - 遊戲沒有全服成交紀錄，7 日數據是中控自己定時記錄的，**從開始使用那天起累積**。需要至少一個遊戲分頁開著才會掃描；同一時間只會由一個分頁負責掃描。
- **我的攤位**：每個帳號的攤位狀態、上架數（每攤最多 50 件）、待領收益、商品；「最近成交」彙整所有帳號攤位的成交紀錄。勾選「自動領取攤位收益」會自動領錢。
- **自動上架**：
  - 規則分「道具規則」（用類別、指定道具、排除道具挑選；可設定每隻角色保留幾個不賣）和「裝備規則」（部位、職業、名稱、素質條件）。
  - 定價基準可選：市場最低價／市場中位數／7 日平均最低價／固定價，再加減百分比或楓幣，例如「最低價 −1%」。
  - **每條規則都必須設底價**，算出來低於底價就用底價；沒有指定對象或沒設底價的規則不會生效。
  - 不會上架的情況：定價不高於商店收購價（賣商店更划算）、行情超過 12 小時沒更新、查不到行情（可改成「用底價上架」）、補給使用中、已鎖定、不可交易。
  - 模式：關閉／試跑（只在紀錄寫會怎麼上架）／自動上架，並勾選套用的角色。每 3 分鐘檢查一次；沒有攤位會自動開一個。
  - 「預覽」可以看到每隻角色現在會上架什麼、價格怎麼算的、哪些不上架和原因。
  - 裝備是用同名裝備的掛單比價，素質不同價格可能差很多，底價請保守設定。
  - 已經在攤位上的商品不會自動改價；被別人削價時要自己在遊戲裡下架重上。

### 知識王
- 開啟「自動作答」後，每個設定檔的遊戲分頁會定期檢查，今天還有次數就開始答，題庫有的直接作答。
- 題庫沒有的題目會停在那一題（遊戲作答不限時），出現在「等你作答的題目」，你點選答案後腳本會接著答完。
- 不論自動或手動作答，答完看到的正確答案都會自動收進你電腦上的題庫。
- 內建題庫在 `quiz-bank.json`，歡迎發 PR 補充。

## 三、自動更新

- **中控伺服器**：每 2 分鐘到 GitHub 檢查一次；有新版而且沒有工作在執行，就自動更新並重啟（約 5 秒）。不想自動更新的話，取消面板右上角的「自動更新」，改成手動按「立即更新並重啟」。舊版會備份在 `backup/`。
- **遊戲腳本**：功能程式由中控提供，伺服器更新後遊戲頁面會在 2 分鐘內自動重新整理並載入新版（前提是第一、3、4 步設了「總是」）。
- 版本以面板右上角「伺服器 vX · 腳本 n/m 最新」為準。Tampermonkey 清單裡顯示的版本號是載入器本身，會在它自己的每日檢查時才跟上，不影響功能。
- `start.bat` 本身不會自動更新。

## 四、常見問題

| 狀況 | 處理 |
|---|---|
| 遊戲右下角顯示「連不到中控伺服器」 | 確認 `start.bat` 的黑色視窗開著 |
| 遊戲右下角完全沒有提示 | 確認 Tampermonkey 已開啟「允許使用者指令碼」，腳本是啟用狀態 |
| 黑色視窗說找不到 Node.js | 裝完 Node.js 後重新開機再試 |
| 面板「腳本」顯示有分頁不是最新 | 到那個設定檔的遊戲分頁按 F5；仍舊的話檢查第一、3、4 步的「總是」設定 |
| 遊戲顯示「遊戲已更新，請重新整理」 | 遊戲本身改版，重新整理遊戲分頁即可 |
| 想清空所有資料 | 關掉黑色視窗，刪除 `data` 資料夾再重新啟動 |
| 8787 埠被占用 | 用記事本打開 `start.bat`，把 `PORT=8787` 改成別的數字；`szg-hub.user.js` 裡的 `HUB` 與 `@require`、`@connect` 網址也要一起改 |

## 五、檔案說明

| 檔案 | 用途 |
|---|---|
| `start.bat` | 啟動中控（含自動更新後重啟） |
| `server.js` | 本機伺服器，只接受本機（127.0.0.1）連線 |
| `market.js` | 市場行情紀錄、掃描排程、自動上架定價 |
| `dashboard.html` | 面板 |
| `szg-hub.user.js` | 安裝到 Tampermonkey 的載入器 |
| `agent.js` | 在遊戲頁面執行的功能程式（由伺服器提供） |
| `update.js` | 從 GitHub 更新 |
| `quiz-bank.json` | 知識王內建題庫 |
| `data/`（執行後產生） | 你的角色資料、設定、學到的題目，不會上傳 |
