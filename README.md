# 上漲谷中控（szg-hub）

給同時玩很多個帳號的人用的「中控面板」：把每個 Chrome 設定檔裡的 [上漲谷](https://play.szg08.com/game/) 角色資料集中到一個網頁，
並且可以從面板批次交易、整理背包、控制掛機、自動回答知識王。

- 全部在你自己的電腦上執行：一個本機小伺服器（Node.js）＋每個 Chrome 設定檔裡的 Tampermonkey 腳本。
- 不需要、也不會碰任何帳號密碼；資料只存在你電腦的 `data/` 資料夾，不會上傳到任何地方。
- 會動到遊戲資料的操作（交易、賣出、鎖定）都要先在面板上「確認執行」才會開始。

> 📖 **第一次使用請看 [圖文安裝與使用教學](docs/guide.md)**：從下載、安裝 Node.js 和竄改猴、設定、打開遊戲，到每個分頁怎麼用，都有截圖。卡住時也可以把教學網址貼給 AI 助手請它帶你做。

> 使用前請自行確認遊戲的使用規範。本專案與遊戲官方無關，使用造成的任何損失請自行負責。

## 一、安裝（只要做一次）

> 有截圖的詳細步驟見 [圖文教學](docs/guide.md)。

### 1. 安裝 Node.js
到 https://nodejs.org 下載 **LTS** 版，一路「下一步」安裝完成。裝完建議重新開機一次。

### 2. 下載中控並啟動
1. 本頁上方按 **Code → Download ZIP**，解壓縮到固定位置，例如 `D:\szg-hub`。
2. 雙擊 `start.bat`。
3. 出現黑色視窗、顯示「上漲谷中控已啟動」，瀏覽器會自動打開面板 `http://127.0.0.1:8787`。

**玩的時候讓黑色視窗開著**，關掉就停止。

### 3. 每個 Chrome 設定檔都做一次
1. 安裝 [Tampermonkey](https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo)（竄改猴）。
2. 打開 `chrome://extensions` → Tampermonkey →「詳細資料」→ 開啟 **「允許使用者指令碼」**（新版 Chrome 沒開的話腳本不會執行）。
3. 中控開著的狀態下，網址列打開 `http://127.0.0.1:8787/szg-hub.user.js` → Tampermonkey 跳出安裝畫面 → 按「安裝」。
4. Tampermonkey 圖示 →「控制台」→「設定」：
   - 「設定模式」改成 **進階**
   - 找到 **外部（Externals）→ 更新間隔（Update Interval）**，改成 **總是（Always）**

   這一步讓腳本每次載入都拿到中控上最新的功能，之後更新就不用再動 Tampermonkey。

### 4. 打開遊戲
遊戲頁面右下角出現綠色的 **「中控：已連線」** 就完成了，回到面板就會看到這個角色。

---

### Mac
1. 到 [nodejs.org](https://nodejs.org) 安裝 Node.js LTS。
2. 下載中控的 ZIP 解壓縮，雙擊 `start.command`（第一次被擋住：「系統設定 → 隱私權與安全性」按「強制打開」；或在終端機進到資料夾執行 `chmod +x start.command`）。也可以在終端機進到資料夾執行 `node server.js`。
3. 終端機視窗要保持開著；中控自動更新後會自己重新啟動。

## 二、日常使用

### 基本觀念
- **同一個帳號開兩個分頁（A、B 兩隻同時在線）**：遊戲分頁只會顯示一隻角色，另一隻在遊戲伺服器上背景掛機（經驗照拿，但中控拿不到它的最新資料，也不能幫它做事）。在遊戲分頁右下角按「**＋ 開 某某 的分頁**」，會開一個新視窗固定顯示另一隻；或直接再開一個遊戲分頁，腳本發現 A 已經有分頁，會自動把新分頁換成 B。兩隻就同時在線：資料都即時，賣出、存公倉、交易、掛機指令都由各自的分頁直接執行，不用再切換。
  - 兩個視窗都要「看得到」最好：分頁被藏到背景時，遊戲會進離線掛機、畫面暫停更新（經驗照算），中控會標「分頁・背景」，工作照做但比較慢。
  - 同一隻角色不要開兩個分頁：後開的那個會顯示警告並暫停中控功能，關掉其中一個就好。
  - 不想開兩個分頁也可以照舊用「⇄ 切換」把現有分頁換成另一隻。右下角的按鈕會列出同帳號的其他角色：已經有分頁的顯示灰色「已開」（剛關掉的分頁最多 20～100 秒後恢復可開，也可以直接按、確認後開）；按 ✕ 收成一個小的「＋ 分頁」，點一下再展開。
- **一個帳號的第二隻角色第一次出現**：要它有自己的分頁或切換過去一次，才會完整出現在面板上。
- **灰色列**：超過 5 分鐘沒更新，通常是那個設定檔的遊戲分頁沒開。
- **本尊**：在總覽表點 ★ 指定哪隻是本尊，交易的「收集」會把東西集中到本尊。楓幣分布（每隻角色、帳號倉庫）在總覽摘要下方的「楓幣分布」展開。
- **升級時間**：總覽「升級還要」欄用目前每小時經驗算出升下一級要多久；上方填「目標等級」會多一欄「到 LvX」（游標停留可看預計達成時間）。每級所需經驗由腳本回報精確值、自動累積成經驗表（總覽「經驗表」可看現在 vs 原版倍率）；還沒收集到的等級用原版經驗 × 最接近等級的倍率估算，標「估計」。
- **工作佇列**：在畫面右上角的「工作」按鈕（有待確認的工作時會亮起並顯示數量）。交易、賣出、鎖定都會先建立成「待確認」工作，核對內容後按「確認執行」才會開始。執行時相關角色要有自己的遊戲分頁（同一個帳號可以開兩個分頁）。

### 總覽
- **需要處理**：最上方列出現在要注意的事，每項旁邊有一鍵處理按鈕——沒在掛機（▶ 全部開始）、1 小時內到期（↻ 全部重新開始）、離線掛機中（⏏ 全部領取）、遊戲分頁超過 5 分鐘沒回報、待確認或失敗的工作。你自己從中控暫停的角色會另外列一行，不算異常。都沒有時顯示「✓ 一切正常」。
- **角色表**：有自己遊戲分頁的角色標「分頁」（在背景的標「分頁・背景」），沒有分頁的顯示較淡；可切換「只看有分頁的」、搜尋角色／帳號／地圖；「顯示更多欄位」會多出藥水、裝備欄、道具、交易ID。
- 勾選角色後，畫面底部出現操作列 → **▶ 開始掛機／Ⅱ 暫停／↻ 重新開始**（重新開始＝重新計算 24 小時）**／⏏ 領取離線收益／⇄ 切換**。同帳號的第二隻角色也可以直接勾：有自己分頁的由它自己的分頁執行，沒有的由同帳號的分頁代做。
- **楓幣收入（v0.39 起）**：上方讀數列的「楓幣收入／時」是掛機中角色的每小時楓幣加總，「合計賺得」是所有角色本次掛機賺的楓幣，下面附遊戲的累計賺得；角色表的「每小時楓幣」欄可以排序，下面小字是這次賺了多少。數字來自遊戲主控台的掛機報告（本次賺的楓幣 ÷ 掛機時間），這次掛不到 10 分鐘的先不算每小時。
- **小怪（v0.40 起）**：數字列下面有綠水靈和菇菇寶貝走來走去，點牠們會有反應（連點 5 下會倒下再復活）。純裝飾，不想看可以按右上角 × 收起。
- **實戰 DPS**：腳本會「旁聽」遊戲頁面本來就在做的同步，統計每隻角色實際打出的傷害，**不會多送任何請求給遊戲伺服器**。總覽的「實戰 DPS」欄顯示最近 5 分鐘的每秒傷害，點一下展開明細：最近 5 分鐘／1 小時 DPS、有效 DPS（扣掉打超過怪物剩餘血量的溢傷）與效率、爆擊率、平均每次出手與單段最高傷害、每小時擊殺、各技能傷害占比、每分鐘 DPS 走勢、打的怪。
  - 只有遊戲分頁開著的角色才統計得到，每 30 秒更新；連續 3 分鐘以上沒有資料（分頁關掉、離線掛機暫停同步）的時段不算進時間。
  - 這是在目前地圖的實際輸出，會受怪物數量、走位空檔影響，不是角色的理論最大值；要比較角色或配裝，可以用遊戲內建的「傷害測試稻草人」地圖。
- 表格上方的「⚙ 掛機自動規則」展開後可以設定：
  - **死掉自動原地復活**（v0.44 起，預設開）：遊戲自己的自動復活每輪只有 3 次，用完會停在「原地復活／暫時等待」畫面；開啟後中控會自動按原地復活並重新開始掛機。每次死亡扣本級經驗 5%，所以每隻每小時最多自動復活幾次（預設 6），超過就停下來列在「需要處理」，提醒你換地圖。
- **自動續掛**：到期前 N 分鐘自動重新開始；從面板手動暫停的不會被重新開始。
- **掛滿 N 小時自動暫停**。
- 每列的「自動」取消勾選就不套用自動規則。
- **離線掛機**：遊戲在頁面 60 分鐘沒有操作時會進入「離線掛機」，畫面暫停更新，累積的經驗、楓幣、掉落物要按「點一下繼續」才會領回（上限 24 小時）。中控的對應方式：
  - 總覽會標示「離線掛機中」與資料停在幾點，這段期間面板上的楓幣、道具等數字不是最新的。
  - 可以按該列的「⏏ 領取」，或勾選多隻後按「⏏ 領取離線收益」，等於幫你按「點一下繼續」。
  - 交易、背包操作、自動上架執行前，會自動先領取，確保用的是最新庫存。
  - 可勾選「離線掛機每滿 N 小時自動領取一次」（預設關閉），避免超過 24 小時上限而損失收益。
  - **保持在線**（v0.74.4，同一個設定區）：背景執行的分頁沒人操作，一定會在 1 小時後進入離線掛機。預設「背景執行的分頁」一進入離線就自動按「繼續」（約 30 秒內），等於一直在線；可以改成「全部分頁」或「不要」。不會模擬滑鼠鍵盤，只是幫你按遊戲的「繼續」。
  - 公倉自動存入到期時，在離線掛機的角色會先按「繼續」，等補算後的背包回報再存。
  - 中控不會擋遊戲進入離線掛機（那是作者為了減輕伺服器負擔設計的）；保持在線會讓背景分頁一直向遊戲要資料，不需要時可以改成「不要」。
- **切換角色**：沒有分頁的角色旁邊有「⇄ 切換」，按了會把該帳號的遊戲分頁換成那隻並自動重新整理（約 10 秒），原本那隻轉背景掛機；已經有分頁的角色不會被切換（不然兩個分頁會變同一隻）。那個分頁有交易／背包工作在執行時不能切換。背包操作、交易都要那隻角色有自己的分頁才會執行，沒有的話工作會顯示「等待某某的遊戲分頁」，「需要處理」也會提示。

### 裝備
- 上方的「A 組／B 組／全部／自動」只顯示那一組角色的裝備（帳號倉庫照常顯示），交易分頁也共用這個設定；自動＝跟著有分頁的角色比較多的那一組。
- 上方切換 **裝備清單／穿戴對照／撿到自動處理** 三個畫面，旁邊切換「目前素質（含衝卷）／原始（未衝卷）」，你上次看的畫面會被記住。
- 裝備清單上方可直接搜尋名稱、套用常用組合；其他條件在「篩選條件」裡（收合時會顯示目前套用了哪些）。勾「同名合併」會把同名裝備合成一列，後面列出在誰身上（👕＝穿戴中、📦＝倉庫），點背包的名字可以直接選取。
- **穿戴對照**：每隻角色一列、每個部位一欄，列出全部素質；「部位設定」裡這個部位要看的素質會加粗（跟浮動判斷同一份設定）。
- **裝備清單**：可依部位、位置、職業、角色、名稱、需求等級、強化次數、剩餘可衝次數、素質條件篩選，點表頭排序，表頭會固定在畫面上方。
  - 素質條件可用 `>` `>=` `<` `<=` `=` `≠`，條件之間選「且」或「或」。**「且」優先**：`A 且 B 或 C` ＝ `(A 且 B) 或 C`。
  - 除了各項素質，也能用「四屬總和、強化次數、剩餘可衝、總可衝次數、需求等級」當條件。
  - 常用的篩選按「存成組合」，交易和背包的篩選器也能直接套用。
  - 勾選背包裡的裝備 → **鎖定／解鎖／賣出**，會依角色建立工作。
- **撿到裝備自動處理**：
  - 每條規則設定「對象」（部位、名稱、職業）和「保留條件」。新出現在背包、符合對象但不符合保留條件的裝備會被處理；多條規則都套到同一件時，符合任一條的保留條件就保留。
  - 模式：**關閉／試跑（只記錄會賣哪些）／自動賣出**，並勾選要套用的角色。
  - 一律不動：已鎖定、強化過、衝過卷的裝備；剛透過中控交易進來的裝備；開啟前就在背包裡的裝備。
  - ⚠ 腳本只看得到「背包多了哪一件」，分不出是撿到的還是你自己從倉庫拿出來、手動交易收到的。重要裝備請先鎖定，並建議先用「試跑」確認規則正確再開自動賣出。

### 交易
- **收集**：勾選分身，把背包裡可交易的道具、裝備、楓幣送到本尊。可以設定每個分身保留多少 % 楓幣（買藥用）。固定排除：穿在身上的裝備、補給使用中的藥水、已鎖定的物品、倉庫內的東西。
- **給某隻角色**（v0.36 起在背包）：到「背包」勾選物品（可以跨好幾隻角色）→ 底部「**給…**」，在側邊抽屜選收的人、改每樣數量、另外加楓幣；只轉楓幣按「**轉楓幣…**」。會依來源角色各建一個交易工作；已鎖定、補給使用中、同一個帳號的會略過。
- 自動拆成每次最多 20 格；同種道具超過 9999 個會拆到不同批次。
- 安全機制：收貨方只接受清單上指定帳號的邀請，並逐項核對對方放的東西，不符就取消；放東西前會再檢查一次鎖定狀態；任何一步卡超過 3 分鐘自動取消，可按「重試」從失敗的批次繼續。
- 同帳號的兩隻角色不能互相交易，請用倉庫。
- **第一次用建議先小量測試**，例如在背包選一個道具按「給…」，數量改 1。

### 背包
- **條列**：一件一列（裝備每件分開、道具每隻角色一列），看得到強化／可衝次數、掉落浮動、**判斷**（依「浮動判斷基準」，見公倉）。表頭「物品／在誰身上／判斷」可以排序；點整列選取。工具列的「浮動」下拉可以只看達標／未達標／算不出的裝備，條列上方有「選取畫面上浮動未達標、沒鎖定的裝備」，選好按賣出。
- 上方是**角色卡**：每隻角色的道具數、裝備數、可賣金額、狀態（綠＝有自己的遊戲分頁、黃＝背景掛機（沒有分頁）、紅＝離線）。點一張只看那隻，按住 Ctrl 可以多選，再點一次回到全部。
- **依道具**：每種東西一行，後面列出「在誰身上、各有幾個」（🔒＝已鎖定、💊＝補給使用中）。點名字選取那一份，勾最左邊選取所有人的。裝備會把同一隻角色的同名裝備合成一顆（例如「佐藤天司 ×3」），滑過去看每件素質；要單件挑選請用「依角色」。
- **依角色**：每隻角色一塊，用遊戲背包那樣的格子顯示，點格子選取；每塊有「選可賣的／全選」。
- 上方可以搜尋、切換類別（裝備／消耗／卷軸／其他），勾「只看可賣」「隱藏已鎖定」；「更多篩選」裡有指定／排除道具、套用裝備篩選組合。
- 勾選後畫面底部出現**動作列**：已選幾項、幾隻角色、賣出大約多少楓幣 → **賣出／鎖定／解鎖**。會依角色各建一個工作，到右上角「工作」確認執行。賣出時會再跳過鎖定的物品與補給中的藥水，報價項目比選擇的多時自動停止。
- 各分頁標題旁的「?」是說明，滑鼠移過去或點一下就會顯示。
- 背包和公倉之間搬東西請用「公倉」分頁（左邊背包、右邊公倉並排）。
- 背包工作由那隻角色自己的遊戲分頁執行。同一個帳號開了兩個分頁時，兩隻的工作同時各做各的；只開一個分頁時，**有分頁的那隻先做**，另一隻的工作顯示「等待某某的遊戲分頁」，幫它開分頁或切換過去就會接著做。

### 派工（試用版）
- **城鎮圖（v0.71 起）**：中間是城鎮（背包、商店、公倉、強化四棟），外面那一圈虛線是「共用規則」。v0.73 起 **A、B 組合在一起**：同一張圖只有一個節點，兩組的角色都在裡面（頭像角落標 A／B）。有角色的地圖排在城鎮旁邊，沒有角色的排在外面。
  - 上方「＋ 開新地圖」把地圖放上來，再把上方「**未派遣**」的角色**拖進地圖**。點一下角色＝選取（可以選好幾隻一起拖）；拖回「未派遣」＝取消。
  - **隊伍框**（v0.73）：遊戲裡同隊的角色（2 人以上）用紫色框包起來，標「某某的隊伍」，不在這裡的會顯示幾人／幾人。**拖隊伍框（或隊伍裡任一隻）整隊一起走**，沒組隊的單隻走；點一下隊伍框＝整隊選取。隊伍裡有人等級不夠那張圖，整隊都不動。
  - 上方「全部／A 組／B 組」：只看某一組時，另一組的角色變淡（只是看的，不影響派工）。
  - **點兩下角色**或按頭像右上角的 **i**：打開角色抽屜。
    - **裝備**（v0.71.1）：身上和背包的每件裝備顯示 +幾、剩幾格、卷軸加了哪些素質、浮動；24 小時內從強化工坊出來的標「剛強化」排在最前面。點背包的一件會跟身上同部位比較素質，按「確認穿上」就換上（換下來的放回背包）；身上的可以「脫下」。等級、職業不夠的會擋下來；要那隻角色有自己的遊戲分頁才會執行。
    - **能力點**（v0.72）：可以分配的點數、目前數值和含裝備的數值。照遊戲的做法先在草稿上按 ＋／－／+5／全部，按「**確認分配**」才送出（加了就退不回來，會再問一次）。下面可以編「自動配點」計畫（照順序把每一項加到目標），勾「升級時自動分配」就由遊戲自己配。
    - **技能**（v0.72）：這個職業一路上來的技能，依幾轉分組，顯示 Lv／上限；還不能學的會寫原因（前面的技能要先點幾點、要先學哪招）。一樣是草稿＋「確認分配」。學過的攻擊技能可以按「掛機用這招」，Buff 技能可以勾「自動施放」；下面是「自動配技能」計畫。
    - **掛機設定**（v0.72）：自動喝水、到圖自動開始掛機、自動配點、自動配技能的開關，切了直接送進遊戲。
    - **掛機設定（v0.78 起）**：從遊戲讀出這隻目前那一套（遊戲的 1／2／3）的設定，在中控改完按「套用到遊戲」（會先列出要改的項目再問一次）。可以改 HP／MP 藥水（從背包的消耗品選）、喝水 %、三格 Buff 藥水、自動解除異常（顯示背包有幾個萬能療傷藥，0 個會警告）、用完時停止／繼續、隊友 Buff 三格、隊友／自己補血門檻、自動買水規則（會花楓幣）。上方 1／2／3 切換第幾套（沒用過的那套是空白的，切換前會提醒）；「從遊戲重新讀取」抓最新的。「複製到其他角色」把這隻的補給／Buff／補血設定套到勾選的多隻（藥水不在對方背包、沒有萬能療傷藥、Buff 技能沒學會先警告）。
    - 這三頁都要那隻角色有遊戲分頁（或背景執行）、而且換成新版中控腳本後約 1 分鐘才會有資料。
    - **基本資料**：等級、地圖、分頁狀態、DPS、改到另一組。
  - 地圖拉線到城鎮的建築：這張圖的東西會送去哪裡就有哪條線；**掉落動畫**沿著線飛過去（賣掉的飛到商店、要存公倉的飛到公倉…），建築會列出最近收到的東西。
  - 拖地圖標題移動（會記住）、拖空白處平移、滾輪縮放；「全部顯示」「100%」「重新排列」（排回內外圈）「⛶ 放大畫布」。
- **去處規則（v0.71 起）**：每樣掉落物決定去處——**背包**（留著）、**商店**（撿到就賣，遊戲伺服器處理，分頁沒開也有效）、**公倉**（留著，交給公倉的自動存入）、**強化**（留著給強化工坊）。
  - **共用規則**（城鎮上方或下方工具列的「共用規則」）：裝備、卷軸、技能書、其他道具各要去哪裡，王會掉的東西一律留著或照規則；並打開「**派工地圖套用**」「**野王地圖套用**」（＝野王分頁的掉落篩選，是同一份設定）。
  - **地圖自訂設定**：按地圖右下角的設定鈕，列出這張圖會掉的東西，每樣點選去處（灰字＝沿用共用規則、亮色＝這張圖改過）；「全部恢復共用規則」「沿用遊戲設定」（中控不改這張圖的自動販售）。公倉、強化的指定是全部地圖共用的。
  - **⚡ 立即全部套用**（v0.75，共用規則或野王「掉落篩選」裡）：一鍵把每隻有分頁（含背景執行）的角色所在地圖的自動販售改成規則的結果，照表操課沒開也可以用。遊戲 11/27 把自動販售改成「打勾＝保留」並關掉所有舊設定，更新後按一次就會全部重新開起來（中控會自動換成遊戲的新格式）。
  - **照表操課**（v0.74，共用規則或野王「掉落篩選」裡打開，預設關）：規則設定一次就好。中控每分鐘檢查有遊戲分頁（含背景執行）的角色，在派工看板的地圖（「派工地圖套用」開著）或野王地圖（「野王地圖套用」開著）時，遊戲裡那張圖的自動販售跟規則算出來的不一樣就自動改過去，不用按「套用」，以後的新角色也一樣；「沿用遊戲設定」的圖不動。打開前會顯示現在會先改幾隻，下面「最近自動套用」看紀錄。開著時在遊戲裡手動改的自動販售會被改回來，要改請改中控的規則。
  - 從 v0.70 升級：野王的掉落篩選、派工每張圖的販售範本會自動轉成去處規則，會賣的東西跟原本一樣；原本沒設販售範本的地圖標成「沿用遊戲設定」，想改用規則按「改用去處規則」。
- 按 **▶ 套用派工**（A、B 兩組一起）：要移動的角色換到指定地圖、開始掛機，並把那張圖算好的自動販售設到遊戲；已經在圖上、但遊戲裡的自動販售跟規則不同的也會一起更新。遊戲只接受「角色目前所在地圖」的自動販售設定，所以換圖和設定是一起做的。
- **與遊戲同步**：你在遊戲裡換地圖，看板會跟著改（角色所在的地圖不在看板上會自動放上去；還沒套用的派工以遊戲為準）；在遊戲裡改了某張派工地圖的自動販售，會記成那張圖的自訂設定。可以關掉。
- **空地圖自動移除**：「與遊戲同步」自動放上來的地圖沒有角色超過 10 分鐘就移除；自己加的、按 📌 留著的不會。
- **⤓ 匯入目前設定**：把角色現在的地圖放上看板，並把遊戲裡設好的自動販售記成每張圖的自訂設定。
- **⤓ 匯出設定／⤒ 匯入設定檔**：看板上的地圖（A／B 組）和去處規則存成檔案，備份或給別人用；匯入會合併。誰派去哪不會匯出。
- **A 組／B 組**：每個帳號第 1 隻角色是 A 組、第 2 隻是 B 組。沒有自己分頁的（背景掛機）會半透明：可以先排好，套用時會略過；按「⇄ 某組沒分頁的切過去」一次把整組切過去。角色抽屜裡可以把某隻改到另一組。
- **☰ 清單**：原本的清單畫面（左邊角色池、拖到地圖），一次看一組。

### 副本（v0.77 起，試用）
- 上方「副本」分頁：用自己的角色組遊戲的副本隊（拉圖斯、殘暴炎魔）。選副本、隊長、隊員（隊伍最多 12 人；要有遊戲分頁或背景執行），依序按 ① 建立隊伍 ② 隊員全部加入 ③ 全部準備 ④ ▶ 開始。
- 上方顯示遊戲的規則（參加等級、人數、是否要法師、每人入場費、挑戰時間、每週場數），每隻角色顯示本週剩幾場、是不是法師；人數不夠、拉圖斯沒有法師、等級不到、場數用完會先警告。
- 勾「上鎖」填密碼可以建立上鎖隊伍，自己的隊員加入時中控會自動帶密碼。開始前會列出每人和合計的入場費（開始時才扣費，通關才扣場數）。
- 「隊伍」表格：每隻準備了沒、符不符合進場條件、本週剩幾場。
- 「戰況」每秒更新：王的血量、第幾階段、剩餘時間、準備時間倒數（開場 10 秒只能放輔助技能）、黑球／手臂／熔岩像、物理魔法免疫、血魔歸一／火焰預備，以及每隻隊員的 HP、MP、異常狀態（封印、黑暗、暈眩、鎖水）。戰鬥中可以全部投降或離開副本。
- 戰況（v0.78 起）：每隻隊員對王的累計傷害和占比（0 傷害標紅）、只顯示還沒結束的異常（剩幾秒）；王的回血速度估計、淨輸出、照這速度要多久、能不能在時間內打完（打不完標紅，並寫出至少要多少淨輸出）；黑球剩幾顆和各自血量、第幾波、估下一波（約 100～120 秒）、提示「沒清完會全隊封印」。打完顯示結算：結果、總傷害、每人傷害／占比／死亡次數。
- 第一場實測的拉圖斯（2300 萬血）：王一直回血（約每秒 6 萬），12 人都活著才勉強打得動；黑球沒清完會全隊封印約 30 秒，封印中補不了血。建議打之前：每隻 MP 喝水門檻調高、帶夠藥水、勾「自動解除異常」並帶萬能療傷藥、法師系列留 MP 清黑球。
- 戰鬥要用的藥水、Buff、補血門檻可以在角色抽屜「掛機設定」一隻一隻改，或複製給全隊。

### 組隊（v0.46 起）
- 上方「隊長換圖時隊員跟著換」（預設開）：遊戲裡同一隊、原本跟著隊長在同一張圖而且在掛機的隊員，隊長換圖時自動跟過去；野王地圖、正在打王或組隊的不動。
- 把角色拖進隊伍卡片（或點一下角色再點卡片），每張卡片選一張地圖；第一位（👑）是隊長，點別人的 👑 可以換隊長。每隊最多 6 人。
- 按「▶ 套用」（或「套用全部」）：隊伍已經是這幾個人就只換圖。要加人或減人時，只要遊戲裡現在的隊長還在名單裡，就**沿用原本的隊伍**（v0.68.4 起）：隊上的人不動、新加的人用隊伍代碼加入（可以跨帳號）、拿掉的人由隊長踢出；隊長不在原本的隊伍裡時，才會離開舊隊伍、隊長建立新隊伍、其他人加入。最後一起換到地圖並開始掛機。角色要有自己的遊戲分頁才會執行。
- 「⤓ 從目前隊伍匯入」照遊戲裡現在的隊伍建立卡片；「✦ 自動排一版」用中控的經驗估算，替有分頁的角色排好分組和地圖，檢查後再套用。
- 卡片上方顯示狀態（✓ 已就位／要套用的差異／套用中／失敗原因）。
- **即時經驗**：遊戲畫面的「平均每小時經驗」是整輪掛機的平均，換圖後要很久才看得出差別。中控每 10 秒收到角色的經驗值，自己算「最近 3 分鐘」的每小時經驗：換圖或換隊後重新量，約 1 分鐘開始有數字（「測量中」），3 分鐘後穩定，並和出發前 10 分鐘比較（▲／▼ %）。總覽的每小時經驗下面也會顯示「近 3 分」。只有遊戲分頁開著、沒有在離線掛機的角色量得到。

### 強化（強化工坊）
- 用遊戲的「神匠之魂」批次衝卷：每衝 1 次扣 1 張卷軸＋10 萬楓幣，失敗也會扣一格；**衝卷無法復原**。
- 選**執行角色**（裝備和卷軸要在這隻角色身上）、**裝備**、**卷軸**（只列出適用這件裝備的），再設定：每件衝幾次、成功幾次就停、失敗一次就停、成功幾次算「及格」。設好的可以「存成規則」下次直接套用。
- **試跑估算**：列出會衝哪些裝備（點整列個別勾選／取消，或用「全選／全不選／只選前 N 件」），算出最多／預估要用幾張卷軸、多少楓幣、預估幾件及格；詛咒卷軸會另外算消失機率。
- **能衝幾件**：依身上（含公倉）的卷軸和楓幣算出最多能衝幾次、**保證能衝完幾件**（每件都衝到最多次數也夠）、照預估大約能衝完幾件；按「只選保證的 N 件」一鍵選好。卷軸不夠時，表格會標出「可能輪不到」的裝備。
- 按「建立強化工作」後，要在右上角「工作」**確認**才會開始（工作上會寫最多花費）。執行前會再檢查一次裝備還在、沒鎖定、剩餘次數沒變。
- **自動強化（v0.71.4）**：上面選好執行角色、裝備、卷軸、每件次數、及格條件後，在「自動強化」卡片按「＋ 把上面的設定加成自動規則」。中控會定時（預設 30 分鐘）把背包裡**還沒衝過**的那種裝備，用那隻角色背包裡的卷軸去衝（衝過的不會再自動衝；一隻角色一次一個工作；要有自己的遊戲分頁）。
  - **每次確認**：建立強化工作，等你在「工作」按確認。
  - **每日上限內自動**：先填「每天最多自動花」幾萬楓幣；今天花的（含進行中的）加上這次最多會花的不超過上限就直接衝，超過的、**詛咒卷軸一律**等你確認。
  - 「立即檢查」馬上跑一次；「自動強化紀錄」看每次做了什麼；派工城鎮圖的「強化」建築顯示模式和今天花了多少。
- 「強化結果」標題直接列出衝到 +幾 的分布（例如 +5 ×1、+4 ×6），展開可以看每件的 +幾、增加的素質、是否及格或消失；派工城鎮圖的「強化」建築也會顯示上次結果。
- **分流**：每筆結果下面可以把及格／不及格的裝備各自處理——及格：鎖定在身上、交給別的帳號的角色（依職業、等級建議）；不及格：賣給商店、鎖定。會記住上次的選擇；賣出、交易一樣要在「工作」確認。派工城鎮圖的「強化」建築會提示還有幾件等你分流。

### 自動化總表與共用設定（v0.36 起）
- 總覽「自動化」（v0.37 起是滑動開關，一按就開關；撿到裝備自動處理、自動上架開啟時會先問要直接執行還是試跑）列出所有自動功能（掛機續掛、撿到裝備自動處理、公倉自動存入、市場掃描、自動上架、攤位逾時下架、輪流打野王、領攤位收益、知識王、遊戲自動販售、中控更新；逾時下架和打野王要到各自的頁面開），顯示開／試跑／關和最近一次動作，點一下跳到設定。
- 所有「套用的角色」都是同一個選擇器：全部／A 組／B 組／有分頁的／自訂。前四種會自動跟著角色變動。
- **部位設定**：每個部位、每種武器判斷浮動要看哪些素質（預設：物理武器看物攻、法杖看魔攻、防具和飾品看力量、敏捷、智力、幸運）。裝備頁、背包、公倉、撿到自動處理、自動上架都用這一份；撿到自動處理和自動上架的條件可以選「浮動達標（1＝是）」「浮動分數」，規則裡有「＋ 保留浮動達標的」一鍵加上。

### 知識王共享題庫（v0.38 起）
- 所有人的中控一起累積題庫：答完題遊戲公布的正確答案會自動上傳到共享題庫，每 30 分鐘下載一次別人累積的；遇到題庫沒有的題目會馬上再抓一次，別人答過就不用停下來等你。
- 只上傳遊戲公布的正解（自己在面板猜的不傳），只送題目、選項、答案和一組匿名編號，不送角色名稱、帳號。
- 同一題有不同答案時，以最多不同中控回報的為準，同票先不提供；每個中控同一題只算一票。題庫優先順序：自己學到的 ＞ 共享題庫 ＞ 內建 ＞ 冒險資料庫。
- **預設加入**；知識王頁「加入共享題庫」開關可以關掉。想自己架一份：把 `tools/quiz-share.gs` 貼到自己的 Google 試算表（擴充功能 → Apps Script），部署成網頁應用程式（執行身分：我、存取：所有人），把網址填到「進階：改用自己的題庫網址」。

### 公倉（公會倉庫）
- 前提：角色已經加入公會、遊戲裡打得開公會倉庫。中控只會動**背包裡**沒鎖定、可交易、不是補給設定中的東西。**楓幣和點數**只有你在「楓幣／點數」自己填金額、建立工作並確認後才會存入或提領，自動存入永遠不碰。
- **版面（v0.35 起）**：
  - 上方**狀態列**：公倉名稱、道具／裝備容量（快滿變橘、滿了變紅）、楓幣、點數、自動存入狀態和規則摘要；右邊三個按鈕：重新整理、存入規則、楓幣／點數。
  - 下面**左邊背包、右邊公倉並排**，上方的類別（卷軸／消耗／其他／裝備）和搜尋兩邊一起篩。左邊點選要存的（可以只看某隻角色、A 組或 B 組；裝備有「選達標的／選未達標的」），按中間「**存入 →**」；右邊點選要領的，選「道具領給」誰（裝備照每件的「給誰」，已依職業等級建議），按「**← 領取**」。兩個方向都可以再搬回來，所以按了就直接執行。
  - 「存入規則」和「楓幣／點數」從右側抽屜打開（Esc 關閉）。
- **自動補給（v0.78 起，預設關）**：狀態列「自動補給」打開。每條規則＝道具（從公倉裡有的選）、背包低於幾個、補到幾個、哪些角色（全部／A／B／有分頁的／自訂，點整列勾選）。中控每 2 分鐘檢查一次，低於就從公倉領到設定的數量；公倉不夠就領能領的（背包最少的先分），同一隻同一道具 10 分鐘內不重複領；副本戰鬥中、不在線、背包滿的跳過。**只領道具，不會動楓幣和點數**。下面有最近紀錄和「立即檢查一次」。背包數字大約每 45 秒更新一次，所以低於之後最多要幾分鐘才會補。
  - 第一次使用時上方會出現設定引導，完成後自動收起。
- **存入規則**（抽屜；手動、自動存入共用，改了自動存檔）：
  - **快速套用**：「只存卷軸」「卷軸＋全部裝備」「卷軸＋比標準好的裝備（依部位基準達標）」，一鍵設好。
  - **哪些角色**：預設全部角色（之後新增的也算）；可以只選 A 組／B 組，或個別勾。
  - **整類存入**：所有卷軸／所有裝備／所有消耗品／所有其他道具，會包含之後撿到的新東西。只想存特定幾種就用「個別挑選」（點整列選取）。
  - **裝備條件**：用「掉落浮動」（掉落時的數值 − 標準值，不含衝卷）篩選。建議用「**依部位基準達標**」，每個部位、武器各自判斷；也可以用單一素質（例如物攻 ≥ 2）或浮動總和；可設全部符合或符合任一。
  - **浮動判斷基準**：每個部位、每種武器要看哪些素質。預設：物理武器看物攻、短杖／長杖看魔攻、防具和飾品（含手套）看力量、敏捷、智力、幸運；分數＝這些素質的浮動加總，分數 ≥ 門檻（預設 1）＝達標。點素質切換、改門檻，或一鍵套用到同類；背包的「條列」也用同一份。
  - **道具保留**：每隻角色每種留幾個在背包，多的才存。
  - 上方摘要會用一句話寫出「會存什麼、從誰身上、保留多少」。
- **自動存入**（存入規則抽屜最上面）：「依規則建立存入工作」手動存一次（到右上角「工作」確認）；或開**自動存入**：先用「試跑」看紀錄，沒問題再改「自動存入」，每隔設定的分鐘數替有自己遊戲分頁的角色存入（不用確認），公倉快滿時自動停止。下面的預覽會列出這次會存幾件、哪幾件符合條件。
- **公倉內容**（右邊）：按「重新整理」讀取（或在遊戲裡打開公倉一次）。分成**卷軸、消耗、其他、裝備**四頁；裝備頁可以用浮動條件或「浮動達標／未達標」篩選。點整列選取（Shift＋點選一段），選「給誰」後建立領取工作；裝備會依職業、等級先建議剛好能穿的角色。不要的裝備可以「賣掉勾選的裝備」：由指定角色每次領出一批、馬上賣給商店。
- **楓幣、點數**（抽屜）：上方切換「存入公倉」或「從公倉提領」。
  - 存入：每隻角色填要存的楓幣（點數是整個帳號共用，每個帳號一列），可以「每隻保留 N，其餘全部存」「每個帳號點數全部存」快速填入。
  - 提領：在要拿到錢的角色那一列填金額，合計不能超過公倉餘額；會被扣公會稅，面板會先估算稅後金額，實際拿到多少寫在工作紀錄。
  - 建立的工作要在「工作」按確認（單一確認或「全部確認」都可以，全部確認前會列出金額再問一次）。執行時會先讀公倉、確認餘額夠，做完把公倉和身上的餘額變化寫進紀錄。
- 強化的「分流」也可以選把不及格的裝備存進公倉；派工城鎮圖的「公倉」建築顯示自動存入狀態和流向。

### 野王（v0.69 起，原本的「地圖」分頁）
- **怎麼開始**：分頁上方有三個步驟提示——① 選誰打哪隻王 ② 掉落篩選（可略過）③ 先「試跑」看紀錄，沒問題再切「自動出發」。
- **依王看**（預設）：每隻野王一張卡片，依「打王中 → 已重生 → 快重生」排序。
  - 卡片右上：已重生／多久後重生／打王中幾 %。下面是王的 HP、上次打到剩多少、**預估要打幾分鐘**（打很久的王標 ⏳）。
  - 卡片上列出會打這隻王的角色和各自的狀態（可打、還要多久、太久、稍後、打王中）；**點角色＝不讓它打這隻王**，「＋ 加角色」讓更多角色打（也可以一鍵「加入等級夠的」）。同隊伍、跟著一起去的隊友用虛線標「隊友」。
- **依隊伍看（v0.69.3 起）**：一個隊伍一張卡片：隊員、合計 DPS、誰還沒準備好（沒有遊戲分頁、沒在掛機…）、會打哪些王。每個隊伍各自選「一起打同一隻／各自分開打／依王決定」；沒設的隊伍用 ⚙ 設定裡的預設。
  - **隊伍不打的王（v0.69.4 起）**：卡片上點王的名字切換打不打（🚫＝這隊不打，不管一起打還是各自打都不會去；不會改到角色自己的勾選）；選「依王決定」時，王名字旁的 👥／👤 切換整隊一起打或各自打。
  - **一起打**要全員能出發才會去（不會有人自己先去被打死）；隊友倒下會原地復活繼續打（同一隻倒第 3 次才放棄）；有人回去（被停止、打不動、倒太多次）整隊一起回練功圖，連續打也一樣。
- **依角色看**：每隻角色一張卡片，點王的名字選這隻要打哪些王；「全部／等級內／複製給…／清除」。
- **💰 掉落篩選**（v0.69 起）：角色到了王的地圖時，中控會自動把那張圖的「自動販售」設好（撿到就賣給商店）。
  - 共用規則套用到全部的王：小怪掉的裝備、卷軸、技能書、其他道具各自選「賣掉／保留」，**👑 王會掉的東西預設一律保留**。
  - 某隻王要例外就按「調整」個別勾（💰＝賣、👑＝王會掉的），可以「恢復共用規則」。王的卡片下方會顯示用哪一種、賣幾項。
  - 預設關閉；回練功圖後練功圖用它自己原本的自動販售設定。
- **⚙ 設定**：隊伍打王（整隊一起／各自分開／依王決定）、連續打（打完一隻直接去下一隻，全部打完才回練功圖）、預估超過幾分鐘打不死的不去（預設 15，想打海怒斯、噴火龍這種血多的王要調大）、掛機設定組合（遊戲的 1／2／3）。
- **一定回練功圖（v0.69.2 起）**：練功圖本身也有野王（例如海岸草叢3）時也會正確記住原本的地圖；打完王約 1.5 分鐘後角色若還停在王的地圖（回程失敗、分頁重新整理等），中控會自動帶回原本的地圖並開始掛機。
- **強制停止（v0.69.1 起）**：上方「正在打」每隻角色有「⏹ 停止」（只停那隻）、「⏹ 全部停止」，王的卡片打王中也有「⏹ 強制停止，回練功圖」。被停的角色放棄這隻王、回原本的地圖重新開始掛機，王的血量遊戲會保留；30 分鐘內不會再被派去打王（摘要旁按「恢復」可以馬上解除）。手機版打王分頁也有。
- **打到什麼時候（v0.69 起）**：王的血量有在掉就**一直打到死**，中途不會因為時間到被連續打拉去別的王；血量 3 分鐘（可改）完全沒下降才先回去（遊戲會保留王的血量，30 分鐘後再來）。另有安全上限（預設 180 分鐘）。
- 每分鐘檢查一次：有勾王的角色**在掛機、有自己的遊戲分頁（或背景執行）**時，挑一隻已經重生的王（預估最快打死的先去），換過去開始掛機，打死後換回原本的地圖並重新開始掛機。野王是每隻角色各自一份、同隊伍共用一份，所以同隊的會一起出發。不會使用付費重生。
- 「地圖查詢」「掉落物查詢」搬到「圖鑑」分頁；批次換圖、練功效率提示、組隊效率試算拿掉了（組隊分頁的「✦ 自動排一版」照常可用）。

### 市場（自由市場）
- **行情**：中控會定時（預設每 3 小時，可改）用遊戲的市場搜尋查詢「所有帳號背包裡有的道具」，記錄：
  - 市場最低價、前 50 件的中位數、掛單筆數／總數量（都是**單件價**，並**排除自己帳號的掛單**）
  - 7 日最低／平均／最高、漲跌（和約一天以上前比）、每日走勢
  - 你所有帳號持有的數量與估值（持有 × 市場最低價）
  - 點一列可以展開目前最便宜的幾筆掛單。
  - 遊戲沒有全服成交紀錄，7 日數據是中控自己定時記錄的，**從開始使用那天起累積**。需要至少一個遊戲分頁開著才會掃描；同一時間只會由一個分頁負責掃描。
- **我的攤位**：每個帳號的攤位狀態、上架數（每攤最多 50 件）、待領收益、商品；「最近成交」彙整所有帳號攤位的成交紀錄。勾選「自動領取攤位收益」會自動領錢。
- **逾時下架（v0.41 起）**：在「我的攤位」設定。上架超過設定時數（預設 24 小時）沒賣出的商品，自動下架回那隻角色的背包。
  - 遊戲的商品沒有上架時間，中控從**第一次看到它在攤位上**開始計時（攤位約 5 分鐘回報一次）；有人買走一部分就重新計時。
  - 下架過的東西**之後不再自動上架**，清單在「逾時下架過、不再自動上架的東西」，按「恢復自動上架」就會照規則再上。
  - 有「試跑」可以先只記錄會下架什麼。
- **自動上架**：
  - 規則分「道具規則」（用類別、指定道具、排除道具挑選；可設定每隻角色保留幾個不賣）和「裝備規則」（部位、職業、名稱、素質條件）。
  - 定價基準可選：市場最低價／市場中位數／7 日平均最低價／固定價，再加減百分比或楓幣，例如「最低價 −1%」。
  - **每條規則都必須設底價**，算出來低於底價就用底價；沒有指定對象或沒設底價的規則不會生效。
  - 不會上架的情況：定價不高於商店收購價（賣商店更划算）、行情超過 12 小時沒更新、查不到行情（可改成「用底價上架」）、補給使用中、已鎖定、不可交易。
  - 模式：關閉／試跑（只在紀錄寫會怎麼上架）／自動上架，並勾選套用的角色。每 3 分鐘檢查一次；沒有攤位會自動開一個。
  - 「預覽」可以看到每隻角色現在會上架什麼、價格怎麼算的、哪些不上架和原因。
  - 裝備是用同名裝備的掛單比價，素質不同價格可能差很多，底價請保守設定。
  - 已經在攤位上的商品不會自動改價；被別人削價時要自己在遊戲裡下架重上。
  - 市場顯示的是**掛單價**，不是成交價。很多人把藥水、雜物掛天價（例如紅藥水一個 100 萬），掛價超過商店收購價 1000 倍（可調）的會標 ⚠ 疑似亂掛：持有估值改用商店收購價，自動上架也會跳過（卷軸、裝備商店價很低但本來就值錢，不做這個判斷）。「我方成交」欄是你自己帳號實際賣給別人的單價（自己帳號互買不算），估值會優先用它。

### 知識王
- 開啟「自動作答」後，每個設定檔的遊戲分頁會定期檢查，今天還有次數就開始答，題庫有的直接作答。
- 題庫沒有的題目會停在那一題（遊戲作答不限時），出現在「等你作答的題目」，你點選答案後腳本會接著答完。
- 不論自動或手動作答，答完看到的正確答案都會自動收進你電腦上的題庫。
- 「各帳號今日狀態」會顯示每個帳號目前在做什麼，沒在答題時會寫原因（例如：未開啟、今日次數用完、等你作答第 N 題、最近錯誤）。
- 遊戲回「存檔忙碌」時會自動等一下再試，不會因此中斷；同樣的錯誤 10 分鐘內只記一次。
- 沒開自動作答、或今天次數用完時，腳本不會一直向遊戲同步，減少對伺服器的請求。
- 內建題庫在 `quiz-bank.json`，歡迎發 PR 補充。

### 外部資料庫（圖示與題庫）
- 道具／怪物圖示、需求與說明，以及額外的知識王題庫，來自 [上漲谷｜冒險資料庫](https://dong811205.github.io/szg-database/)（作者 dong811205），感謝整理。
- 本專案**不附帶**這份資料：中控伺服器啟動後會自動下載一次，之後每天更新，存在 `data/extdb.json`。知識王分頁的「外部資料庫」可以看下載狀態、手動更新。
- 答案的優先順序：你自己學到／更正的 → 內建題庫 → 冒險資料庫。
- 圖示是直接從遊戲伺服器載入的，面板要能連上 play.szg08.com 才看得到。

### 手機版（v0.53 起）
用手機看每隻角色的狀態，也能直接操作：開始／暫停掛機、換圖、確認工作、切換打王、套用組隊。手機透過 **Tailscale**（免費的私人網路）連回家裡電腦，中控不會開放到網際網路上。

📖 **完整圖文步驟與疑難排解：[docs/mobile.md](https://github.com/Arashi9910/szg-hub-public/blob/main/docs/mobile.md)**（也可以把這個網址貼給 AI 助手，請它帶你一步一步裝；文件最後有給 AI 看的說明）

簡要流程：
1. 電腦和手機都裝 Tailscale，登入**同一個帳號**。
2. Tailscale 後台 DNS 頁面確認 MagicDNS、HTTPS Certificates 都已開啟。
3. 電腦用「命令提示字元（系統管理員）」執行一次 `tailscale serve --bg 8787`。
4. 中控面板右上角「📱 手機」→「新增這支手機」，用手機相機掃 QR code。
5. 用掃出來的網址「加到主畫面」（iPhone 請用 Safari）。

### 背景執行（v0.57 起，試用）
不用開 Chrome 視窗也能掛機：中控自己在背景開 Chrome（看不到視窗）跑遊戲和中控腳本，面板、手機一樣能下指令。
1. 面板右上角「🖥 背景」→ 填名稱 →「＋ 新增背景帳號」（一個遊戲帳號一個）。
2. 按「登入」：會開一個**一般的 Chrome 視窗**（獨立的資料夾 `data/bg/<編號>`，和你平常的 Chrome 分開）。用 Google 登入遊戲、看到遊戲畫面後**直接關掉那個視窗**，背景就會自動開始。
   - 出現「這個瀏覽器或應用程式可能有安全疑慮」：代表是在中控控制的視窗裡登入（例如「顯示」的視窗），Google 會擋。請按帳號的「登入」，在跳出來的一般視窗登入；v0.74.1 起在「顯示」的視窗按 Google 登入，中控會自動換成登入視窗。
3. 開始後勾選要在背景開的角色（點整列就能勾；同一個帳號最多兩隻同時在線）。

- 你平常的 Chrome 也開著同一隻角色時，背景那頁會自動暫停，不會重複做事；關掉後約 1～2 分鐘自動接手。
- 中控自動更新重新啟動時背景不會中斷；正常關掉中控的黑色視窗時，背景 Chrome 會一起關。
- 需要 **Node.js 22 以上**和 **Google Chrome**（找不到 Chrome 時，面板裡可以填 `chrome.exe` 的路徑）。每個背景分頁大約用 150～300 MB 記憶體。
- 登入過期時面板會顯示「需要登入」，再按一次「登入」。這是試用功能，有問題請回報。

**「帳號」分頁（v0.58 起）**：帳號很多時用這頁管理。
- 表格直接改名稱、Google Email、備註；拖曳左邊 ⠿ 調整順序；點整列勾選後，上面的按鈕只處理勾選的帳號（沒勾就是全部）。
- **匯出／匯入 CSV**：可以用 Excel 或 Google 試算表編輯後匯入，一次加很多帳號。欄位：名稱、Email、遊戲ID、背景角色ID、開啟（是／否）、備註；依 Email（沒有就依名稱）對到現有帳號，順序照檔案。
- **🔑 批次登入**：依序跳出每個帳號的登入視窗，第一次登入會多開一頁 Google 登入並帶入 Email；你輸入密碼（和驗證碼）、看到遊戲畫面後關掉視窗，就自動換下一個。中控不會儲存密碼；Chrome 問要不要儲存密碼時可以選儲存。
- **點角色名字**：那個帳號會換成看得到的 Chrome 視窗並顯示那隻角色（中控腳本照跑），按「🙈 隱藏」或直接關掉視窗就回到背景。
- 總覽可以按「⠿ 自訂順序」拖曳排角色、會記住；「照帳號頁順序」一鍵照帳號分頁排。

### 更新公告（v0.59 起）
面板右上角「📢 更新」列出最近 5 次更新做了什麼、新功能怎麼用；中控更新到新版後第一次打開面板會自動跳出來，有沒看過的更新時按鈕會亮紅點。

## 三、自動更新

- **中控伺服器**：每 2 分鐘到 GitHub 檢查一次；有新版而且沒有工作在執行，就自動更新並重啟（約 5 秒）。不想自動更新的話，取消面板右上角的「自動更新」，改成手動按「立即更新並重啟」。舊版會備份在 `backup/`。
- **遊戲腳本**：功能程式由中控提供，伺服器更新後遊戲頁面會在 2 分鐘內自動重新整理並載入新版（前提是第一、3、4 步設了「總是」）。
- 版本以面板右上角「伺服器 vX · 腳本 n/m 最新」為準。Tampermonkey 清單裡顯示的版本號是載入器本身，會在它自己的每日檢查時才跟上，不影響功能。
- `start.bat` 本身不會自動更新。

## 四、常見問題

| 狀況 | 處理 |
|---|---|
| 遊戲右下角顯示「連不到中控伺服器」 | 確認 `start.bat` 的黑色視窗開著 |
| 遊戲右下角完全沒有提示 | 確認 Tampermonkey 已開啟「允許使用者指令碼」，腳本是啟用狀態 |
| 黑色視窗說找不到 Node.js | 裝完 Node.js 後重新開機再試 |
| 面板「腳本」顯示有分頁不是最新 | 到那個設定檔的遊戲分頁按 F5；仍舊的話檢查第一、3、4 步的「總是」設定 |
| 遊戲顯示「遊戲已更新，請重新整理」 | 遊戲本身改版，重新整理遊戲分頁即可 |
| 想清空所有資料 | 關掉黑色視窗，刪除 `data` 資料夾再重新啟動 |
| 8787 埠被占用 | 用記事本打開 `start.bat`，把 `PORT=8787` 改成別的數字；`szg-hub.user.js` 裡的 `HUB` 與 `@require`、`@connect` 網址也要一起改 |

## 五、檔案說明

| 檔案 | 用途 |
|---|---|
| `start.bat` | 啟動中控（含自動更新後重啟） |
| `start.command` | Mac 雙擊啟動中控（含自動更新後重啟） |
| `server.js` | 本機伺服器，只接受本機（127.0.0.1）連線 |
| `market.js` | 市場行情紀錄、掃描排程、自動上架定價 |
| `dashboard.html` | 面板 |
| `szg-hub.user.js` | 安裝到 Tampermonkey 的載入器 |
| `agent.js` | 在遊戲頁面執行的功能程式（由伺服器提供） |
| `bg.js` | 背景執行：在背景開 Chrome、注入中控腳本 |
| `update.js` | 從 GitHub 更新 |
| `quiz-bank.json` | 知識王內建題庫 |
| `data/`（執行後產生） | 你的角色資料、設定、學到的題目、背景執行的 Chrome 登入資料（`data/bg/`），不會上傳 |
